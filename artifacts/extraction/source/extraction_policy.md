# Source extraction policy

The source index preserves a coordinate-backed representation of the CSfC MSC Capability Package version 1.3.0. Physical PDF pages run from 1 through 66. Printed main-body page numbers are seven lower than physical PDF page numbers.

Every literal U+002E period ends a prose sentence, including periods inside abbreviations, decimal numbers, URLs, citations, and captions. The period remains in the sentence. Prose in the body, glossary, figure captions, table captions, and footnotes follows the same rule. Headings, contents entries, labels, table rows, table headers, and page furniture have separate types. A prose segment without a final period becomes trailing text. Physical page boundaries do not end sentences; the twelve interrupted prose passages retain both source locations.

Whitespace normalization replaces each run of Unicode whitespace with one ASCII space and trims boundary whitespace. No punctuation, spelling, hyphens, capitalization, or ligatures are silently changed. Original extracted strings and individual PDF character boxes remain in baseline records. The correction ledger separately records the one visually verified Table 1 correction caused by displaced text in the PDF layer.

The structural correction ledger records a repaired reference-table boundary on physical page 64. The RFC 4303 publication date is December 2005. The year previously occupied a separate trailing-prose record; the corrected row now contains the complete date. The ledger preserves the old records and retires that stray source ID. All surviving source IDs remain unchanged.

Each logical table row has one source ID. Ten rows continue across physical pages; their fragments, original cells, repeated headers, and all locations remain available. The logical_cells field joins corresponding column text across fragments for readable interpretation. The raw_text and text fields retain physical-fragment order. Header, title, and applicable note source IDs provide context without duplicating source occurrences. Appendix B and the unruled Appendix C reference list are table data. Appendix C has no printed header; its contextual column labels are explicitly marked as interpretations.

Figure images have separate source IDs. Their 131 label occurrences are manually transcribed from inspected 200 dpi crops. Label records preserve line breaks and approximate relative positions. Label bounding boxes identify the full figure rather than an individual word. Raw Tesseract text and TSV coordinates are retained for comparison; OCR errors are not treated as authoritative source quotations. Two decorative raster bands occur on each page; the bands are page design rather than network figures. The retained PDF and all 66 rendered pages preserve those bands.

Mechanical validation covers every searchable non-whitespace PDF character, exact baseline span partitions, normalized quotations or declared corrections, literal-period counts, table fragment counts, and source links. The independent Perl count uses the exported prose scope. These checks do not establish semantic correctness. The semantic review and unresolved-issue records report that separate assessment.
