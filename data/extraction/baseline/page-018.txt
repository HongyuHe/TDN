Additionally, filtering components are included between the components used for management of the
Gray Networks themselves (namely, AWs and locally run CAs) and Inner Encryption Components that
support Red Networks of a lower security level than the Red Network with the highest security level
supported by the solution. In other words, AWs and locally run CAs on Gray Networks are treated as,
and grouped with, the Inner Encryption Component for the Red Network with the highest security level.
One or more Gray Firewalls must be included in the Gray Network to perform filtering. Standalone Gray
Firewalls have been placed at each site between the Inner Encryption Components and the Outer
Encryption Component; these Gray Firewalls are responsible for dropping packets between Inner
Encryption Components of different security levels.
